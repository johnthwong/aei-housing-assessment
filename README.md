# AEI Housing Center — Assessment Data Package

Baldwin County, Alabama (FIPS `01003`) property records.

## Important: this data has been altered

The underlying records are licensed and contain personal information, so before
release every identifier, name, and address was replaced with a synthetic
value, values and dates were perturbed with random noise, coordinates were
displaced, and a random share of parcels was removed.

The structure, the messiness, the missingness, and the relationships between
files are all real. **The numbers are not.** Nothing here supports a real-world
conclusion about Baldwin County, and it should not be used or cited outside
this assessment.

## Format

Each `.zip` holds a single `.txt`:

- Pipe (`|`) delimited
- One header row of column names
- No quoting, no escape characters
- ASCII
- Empty string means missing

```r
# R
d <- data.table::fread(unzip("Prop01003.txt.zip", exdir = tempdir()),
                       sep = "|", colClasses = "character")
```

```python
# Python
import pandas as pd
d = pd.read_csv("Prop01003.txt.zip", sep="|", dtype=str,
                encoding="ascii", keep_default_na=False)
```

Reading everything as text first is the safer default — several columns that
look numeric carry leading zeros or implied decimal places, which the
dictionary documents.

## Dictionaries

`dictionary_*.csv` has one row per column of the corresponding file:

| Column | Meaning |
| --- | --- |
| `column_position` | 1-based position in the file, matching the header order |
| `field_name` | Column name as it appears in the header |
| `type` | Declared type |
| `lookup` | Name of the code list in `lookups.csv`, when the column is coded |
| `description` | Vendor definition |

`lookups.csv` is long format — `lookup_name`, `code`, `description`. Join it to
a coded column via the `lookup` value in the dictionary.

A small number of columns are undocumented. That gap is in the vendor
dictionary itself and has been left as-is.

## Joining the files

`PropertyID` is the vendor's parcel key and `APN` is the county assessor's
parcel number. Both appear in all four files. They do not behave identically,
and neither joins cleanly everywhere — working out which key to use where, and
what the non-matches mean, is part of the exercise.

## A note on vintages

The four files are not all as of the same date. Check the vintages above.
